## Available context

[llms.txt](/llms.txt) indexes every component and guide. [llms-full.txt](/llms-full.txt) includes
component documentation inline. [Catalog](/r/catalog.json) exposes categories, motion recipes,
intensity, dependency metadata and item/doc URLs. [Registry index](/r/registry.json) lists all
installable items, including shared files and theme items.

For a chosen component, read [Button markdown](/r/button.md) or
[Button payload](/r/button.json). Payloads embed actual source, target paths, dependencies,
metadata and documentation; markdown includes installation and the motion contract. These files
are generated by `pnpm registry:build` (also exposed as `pnpm llms:build`).

## A reliable agent workflow

1. Find the component in the catalog and read its Usage, API, Motion contract and accessibility sections.
2. Configure the consumer's `@cadence` namespace using [Registry](/docs/registry); use one origin/snapshot for transitive dependencies.
3. Install the existing item rather than inventing an incompatible wrapper. Preserve exports, data-slot values and relative imports.
4. Use shared motion presets. Keep `data-motion` and full/reduced/none behavior; test actual interactions in each mode.
5. Leave data fetching, validation and application state ownership with the application. Do not add schema/resolver props.

Authored intensity describes perceptual scope, not runtime preference or motion tier. Do not
turn medium into subtle by deleting motion or silently change a component default.

## Tool boundaries

There is **no Cadence `/api/mcp` service or distributed Cadence agent skill today**. An HTTP-capable
agent can read the generated artifacts; a configured shadcn client can install registry items.
Those capabilities do not imply the proposed list/search/motion-contract MCP tools exist.

The remaining 25 AI components are unscheduled and need their recorded prerequisites. Attachment
and Bubble are available; their presence does not promise streaming, model execution or upload
services. Direction support is deferred. Check the actual catalog rather than speculative names.

## Freshness and reproducibility

Latest URLs revalidate; frozen snapshots retain captured bytes. Read [Registry](/docs/registry)
before pinning. Check source provenance and your consumer lockfile, then run type, keyboard,
accessibility and motion checks in the consuming application. Registry metadata and static parity
checks alone do not prove native event/ref compatibility or live animation cancellation.
