## Unreleased

As of 2026-11-02, this checkout contains 58 documented components and 65 registry items.
The scheduled B1–B9 component batches are implemented. This is repository progress, not a claim
that version 0.5.0 or any other version has been published, tagged, pushed or deployed.

### Added

- Component docs and generated JSON/markdown distribution, with shared theme and motion items.
- Component-page source, TOC, navigation, install controls and supported URL preview shapes.
- Search/category/intensity/complexity catalog filters and persistent accessible documentation navigation.
- Accessibility, registry, AI usage and changelog guides; revalidated current registry responses and explicit retained content snapshots.

### Changed

- Pinned shadcn surface parity checks, runtime motion-helper coverage and docs recipe agreement gates.
- Defined authored motion intensity independently from runtime mode, tier and complexity.
- Registry aliases revalidate instead of promising immutable bytes for changing URLs. Only frozen content snapshots are immutable.

### Still open

The initial JavaScript budget remains 120,000 gzip bytes; the previous production measurement
was 291,423 bytes across 23 scripts. Completing guides does not close that budget, site performance,
T0 responsiveness/performance template enforcement, or cross-library native callbacks/render/refs,
first-paint and live motion cancellation audits. Combobox outside-pointer/Tab/nested compatibility
also remains under review. Remaining 25 AI components are unscheduled; direction is deferred;
Form, Native Select and Sonner are excluded from the parity scope.

## Updates and versions

Cadence copies source into your project. Review diffs and test your application when updating.
`meta.since` is advisory first-appearance metadata, not a published version endpoint. Use the
[Registry guide](/docs/registry) to retain/pin exact artifacts. Release/tag automation and a Cadence
MCP service are not implemented. Future release notes should record actual releases and migration
steps when they exist; this page currently records only Unreleased work.
