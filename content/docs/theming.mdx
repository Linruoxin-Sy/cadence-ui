## Tokens

Cadence does not ship its own color system. It reads the shadcn semantic tokens:

| Token | Used for |
| --- | --- |
| `--background`, `--foreground` | Page and default text |
| `--muted`, `--muted-foreground` | Quiet surfaces and secondary text |
| `--border` | Edges and dividers |
| `--primary`, `--primary-foreground` | Primary actions |
| `--destructive` | Destructive actions |
| `--ring` | Focus rings |

Override those variables the same way you would for any shadcn component. Everything in Cadence
follows, in both themes.

## Motion variables

`cadence-theme` adds the CSS side of the motion tokens:

```css
:root {
  --motion-duration-instant: 100ms;
  --motion-duration-fast: 160ms;
  --motion-duration-base: 220ms;
  --motion-duration-slow: 320ms;
}
```

They exist so a CSS-only component — an overlay that animates through Base UI's `data-starting-style`
/ `data-ending-style` — runs on the same clock as the Motion-driven ones, with no literal duration in
its class list. `[data-motion="reduced"]` shortens them to 0.6×, `[data-motion="none"]` zeroes them,
and a bare `prefers-reduced-motion: reduce` does the same for a page with no provider.

The JS presets live in `components/cadence/lib/motion.ts` and are the source of truth for durations,
easings, springs, and distances.

## Dark mode

Cadence follows the shadcn convention: a `dark` class on `<html>`. Set it before the page paints:

```html
<script>
  const stored = localStorage.getItem("theme");
  const dark = stored ? stored === "dark" : matchMedia("(prefers-color-scheme: dark)").matches;
  document.documentElement.classList.toggle("dark", dark);
</script>
```

## Motion modes

`CadenceProvider` accepts `mode`:

```tsx
<CadenceProvider mode="full">…</CadenceProvider>    // default
<CadenceProvider mode="reduced">…</CadenceProvider> // transform/scale dropped, timing ×0.6
<CadenceProvider mode="none">…</CadenceProvider>    // no animation
```

The OS setting `prefers-reduced-motion: reduce` always wins over `full`. The three modes, how
they resolve, and how to narrow one to a region: [Motion modes](/docs/motion-modes).
