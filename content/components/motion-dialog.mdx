## When to use

- A focused task that must interrupt: confirmations, short forms, destructive actions.
- Content that needs a modal, focus trapping, and a clear escape route.
- Any overlay where closing should feel like the panel "settles back" rather than vanishing.

## When not to use

- Non-blocking hints and menus; use a popover or tooltip.
- Long multi-step flows; use a page or a wizard.
- Mobile sheets with drag gestures; use a drawer component.

## Installation

```bash
npx shadcn@latest add @cadence/motion-dialog
```

## Usage

```tsx
import { MotionDialog } from "@/components/cadence/motion-dialog/motion-dialog";

export function DeleteProject() {
  return (
    <MotionDialog
      trigger="Delete project"
      title="Delete this project?"
      description="This removes every deployment and cannot be undone."
    >
      <div className="flex justify-end gap-2">
        <button className="rounded-md border border-border px-3 py-2 text-sm">Cancel</button>
        <button className="rounded-md bg-destructive px-3 py-2 text-sm text-white">Delete</button>
      </div>
    </MotionDialog>
  );
}
```

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `trigger` | `ReactNode` | – | Content of the trigger button. |
| `title` | `string` | – | Dialog title; required for accessibility. |
| `description` | `string` | – | Optional supporting text. |
| `children` | `ReactNode` | – | Dialog body. |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Max width. |
| `open` | `boolean` | – | Controlled open state. |
| `onOpenChange` | `(open: boolean) => void` | – | Called on open and close. |
| `className` | `string` | – | Merged onto the panel. |

## Motion contract

| Phase | Properties | Token | Interruptible |
| --- | --- | --- | --- |
| enter | backdrop `opacity 0 → 1`; panel `opacity`, `translateY 8px → 0`, `scale 0.96 → 1` | `popup.anchored` (0.4s spring) | yes |
| exit | panel `opacity → 0`, `scale → 0.98`, `translateY 4px` | `popup.anchored` | yes |
| reduced | opacity only | `exit.fade` / `popup.anchored` short | yes |
| none | instant | – | – |

## Keyboard interactions

| Keys | Action |
| --- | --- |
| Tab / Shift+Tab | Cycles focus inside the dialog. |
| Escape | Closes the dialog and returns focus to the trigger. |
| Enter / Space | Activates the focused control. |

## Accessibility

- Base UI provides the modal semantics: `role="dialog"`, `aria-modal`, `aria-labelledby` /
  `aria-describedby`, focus trap, focus return, scroll lock, and Escape handling.
- The close button has an explicit `aria-label`.
- The title is required; a dialog without an accessible name is invalid.
- The panel is removed only after its exit animation finishes, so focus is never lost mid-flight.

## Responsive behavior

The viewport centers the panel and scrolls when the content is taller than the screen. `size` caps the
width; on mobile the panel is always full-width minus page padding.

## Performance

- Only one panel tree is mounted while open; content is unmounted on close.
- Animates opacity and transform only; the backdrop uses a subtle blur (2px), which is cheap but can
  be removed on low-end devices.

## Notes for AI

- Always pass a `title`; it is the accessible name.
- For destructive actions, keep the confirm button's label specific ("Delete project", not "OK").
- If you need a non-modal popover, use Base UI Popover instead of this component.
