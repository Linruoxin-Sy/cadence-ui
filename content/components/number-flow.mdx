## When to use

- Metrics, KPIs, and totals that update while the user watches.
- Prices and counters where a jump would hide the direction of the change.
- Dashboard cards that refresh on an interval or a filter change.

## When not to use

- Currency inputs the user types into; use a controlled input.
- Values that change several times per second (streams, live tickers); the spring never settles.
- Numbers that must be copyable as text; the rendered frames are not stable text.

## Installation

```bash
npx shadcn@latest add @cadence/number-flow
```

## Usage

```tsx
import { NumberFlow } from "@/components/cadence/number-flow/number-flow";

export function Revenue({ value }: { value: number }) {
  return <NumberFlow value={value} prefix="$" precision={0} announce />;
}
```

## Examples

### Percentage with one decimal

```tsx
<NumberFlow value={0.873} precision={1} suffix="%" />
```

### Localized grouping

```tsx
<NumberFlow value={1234567} locale="de-DE" />
```

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | – | The value to display. Changes animate. |
| `precision` | `number` | `0` | Fraction digits. |
| `locale` | `string` | runtime | Locale passed to `Intl.NumberFormat`. |
| `prefix` / `suffix` | `string` | – | Rendered beside the number, outside the animated value. |
| `announce` | `boolean` | `false` | Adds `aria-live="polite"` for result-style values. |
| `className` | `string` | – | Merged onto the wrapper. |

## Motion contract

| Phase | Properties | Token | Interruptible |
| --- | --- | --- | --- |
| change | spring from old to new value, formatted per frame | `number.roll` (0.26s spring) | yes |
| reduced | new value shown directly | – | – |
| none | new value shown directly | – | – |

## Keyboard interactions

None. Not focusable.

## Accessibility

- The element exposes the final formatted value through `aria-label`; intermediate frames stay out of
  the accessibility tree.
- `announce` adds a polite live region for results such as a checkout total. Leave it off for counters
  that change often, or screen readers will chatter.
- Tabular numbers keep the width stable as digits change.

## Responsive behavior

Uses `tabular-nums` and inline flow, so it inherits font size from the container. For very large
numbers, reduce `precision` rather than shrinking the font.

## Performance

- One spring per instance; updates are cheap and do not re-render React.
- Avoid dozens of these on one screen; each runs a frame loop while settling.

## Notes for AI

- Use for numbers that change in place. For editable numbers use an input, for static values use text.
- Keep `announce` off unless the number is a result the user is waiting for.
- Never format inside the parent and pass a string; pass the raw number so the spring can interpolate.
