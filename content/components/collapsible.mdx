## Installation

**Command**

```install
npx shadcn@latest add @cadence/collapsible
```

**Manual**

[Manual installation files](https://cadence.dev/r/collapsible.json)

Copy all nine target files, keeping `collapsible/index.tsx` and the shared
`lib/` directory in the same `cadence/` tree. Preserve relative imports and
the sources' `"use client"` directives. Copy every file in the motion,
utilities and provider payloads, including helpers not imported by Collapsible
directly. The provider files and `motion` package are required imports even
without the optional `CadenceProvider` wrapper.

Complete the base theme setup linked above and ensure Tailwind scans the
copied files. Include the Cadence duration and easing tokens used by the
disclosure classes. No additional item-specific CSS or external asset is
required. Keep the inner measurement wrapper: full mode transitions the
nonnegative measured panel height, while reduced and none update it
immediately. Initially open server-rendered content retains its natural height.
Outer padding and borders remain part of the closing box minimum; put
decoration on a child when the closing endpoint must reach zero.
Standalone components follow the system preference; use `CadenceProvider`
to choose a product mode or override an inherited scope.

The Usage, Controlled and Changing content examples need a client caller for
their local state and event handlers. Use a client caller for refs or
function-valued `render`, `className` and `style` props too. Static
composition with serializable props and children, including element-valued
`render`, can be authored in a Server Component. Persistent content and
Custom render retain their client directives; synchronous `useId` alone
does not require a client caller. A custom Content render must preserve the
supplied props and measurement children.

Usage, Controlled, Custom trigger and Changing content additionally use
`@cadence/button`; Persistent content uses `@cadence/input` and
`@cadence/label`. Install those items separately, or copy every target and
recursive dependency from their Manual panels. The caller owns the boolean
open state, content updates and durable input data. Collapsible provides
disclosure UI; `keepMounted` retains a draft only while mounted, and
`hiddenUntilFound` depends on browser support.

## Usage

A standalone disclosure starts open here. The trigger keeps its expanded state and keyboard semantics; no demo configuration is needed.

```tsx
"use client";

import { useState } from "react";
import { Button } from "@/components/cadence/button";
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/cadence/collapsible";

export function BasicExample() {
  const [open, setOpen] = useState(true);
  return (
    <Collapsible open={open} onOpenChange={setOpen}>
      <div className="flex items-center justify-between gap-4">
        <h3 className="text-sm font-semibold">Project details</h3>
        <CollapsibleTrigger render={<Button variant="outline" size="sm" />}>
          {open ? "Hide details" : "Show details"}
        </CollapsibleTrigger>
      </div>
      <CollapsibleContent>
        <p className="mt-4 rounded-lg border p-4 text-sm">
          Components are copied into your project so you can make them your own.
        </p>
      </CollapsibleContent>
    </Collapsible>
  );
}
```

## Controlled

Own the boolean `open` state in the caller. The external buttons update this example only; the trigger reports requests through `onOpenChange`.

<ComponentExample name="controlled" />

```tsx
"use client";

import { useState } from "react";
import { Button } from "@/components/cadence/button";
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/cadence/collapsible";

export function ControlledExample() {
  const [open, setOpen] = useState(false);
  return (
    <div className="grid gap-4">
      <div className="flex flex-wrap gap-2">
        <Button variant="outline" onClick={() => setOpen(true)}>
          Open from outside
        </Button>
        <Button variant="outline" onClick={() => setOpen(false)}>
          Close from outside
        </Button>
      </div>
      <Collapsible open={open} onOpenChange={setOpen}>
        <CollapsibleTrigger>Account details</CollapsibleTrigger>
        <CollapsibleContent>Your account details stay with the caller.</CollapsibleContent>
      </Collapsible>
      <p role="status">Details: {open ? "open" : "closed"}</p>
    </div>
  );
}
```

## Custom trigger

Compose Button through `render` for a styled native trigger. When rendering a non-button element, set `nativeButton={false}` so Base UI supplies button role, focus and Enter/Space handling. The first disclosure starts open; the second starts closed.

<ComponentExample name="custom-trigger" />

```tsx
"use client";

import { Button } from "@/components/cadence/button";
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/cadence/collapsible";

export function CustomTriggerExample() {
  return (
    <div className="grid gap-4">
      <Collapsible defaultOpen>
        <CollapsibleTrigger render={<Button variant="outline" />}>Button details</CollapsibleTrigger>
        <CollapsibleContent>Initially visible without an entrance animation.</CollapsibleContent>
      </Collapsible>
      <Collapsible>
        <CollapsibleTrigger
          nativeButton={false}
          render={<div />}
          className="w-fit rounded border p-2 focus-visible:outline-2"
        >
          Non-native details
        </CollapsibleTrigger>
        <CollapsibleContent>A div receives the primitive's role, focus and keyboard handling.</CollapsibleContent>
      </Collapsible>
    </div>
  );
}
```

## Disabled

Disable the whole root or one trigger. A disabled, initially open summary stays readable; disabled triggers cannot toggle and are skipped by normal Tab navigation. Other disclosures remain independent.

<ComponentExample name="disabled" />

```tsx
"use client";

import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/cadence/collapsible";

export function DisabledExample() {
  return (
    <div className="grid gap-4">
      <Collapsible disabled defaultOpen>
        <CollapsibleTrigger>Locked project</CollapsibleTrigger>
        <CollapsibleContent>
          This initially open summary remains readable while the root is disabled.
        </CollapsibleContent>
      </Collapsible>
      <Collapsible>
        <CollapsibleTrigger disabled>Unavailable details</CollapsibleTrigger>
        <CollapsibleContent>Not available yet.</CollapsibleContent>
      </Collapsible>
      <Collapsible>
        <CollapsibleTrigger>Available details</CollapsibleTrigger>
        <CollapsibleContent>You can still open this independent section.</CollapsibleContent>
      </Collapsible>
      <a href="/docs/installation">Read the installation guide</a>
    </div>
  );
}
```

## Persistent content

Put `keepMounted` on Content to retain this native input and its draft when closed. Closed content leaves the focus order. Persistence lasts while the example is mounted; store durable drafts in the caller.

<ComponentExample name="persistent" />

```tsx
"use client";

import { useId } from "react";
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/cadence/collapsible";
import { Input } from "@/components/cadence/input";
import { Label } from "@/components/cadence/label";

export function PersistentExample() {
  const id = useId();
  return (
    <Collapsible defaultOpen>
      <CollapsibleTrigger>Workspace draft</CollapsibleTrigger>
      <CollapsibleContent keepMounted>
        <Label htmlFor={id}>Workspace note</Label>
        <Input id={id} defaultValue="Keep this draft" />
      </CollapsibleContent>
    </Collapsible>
  );
}
```

## Searchable content

Put `hiddenUntilFound` on Content to use `hidden="until-found"` while closed. Supporting browsers can reveal this reference through find-in-page; browser support varies. This option overrides `keepMounted`. It is not a search service or a promise of cross-browser Find UI support.

<ComponentExample name="searchable" />

```tsx
"use client";

import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/cadence/collapsible";

export function SearchableExample() {
  return (
    <Collapsible>
      <CollapsibleTrigger>Reference notes</CollapsibleTrigger>
      <CollapsibleContent hiddenUntilFound>
        Cobalt delivery reference: use your order number when contacting support.
      </CollapsibleContent>
    </Collapsible>
  );
}
```

## Changing content

The button adds or removes local detail in this example. The inner natural content is observed and the open panel follows its height, including responsive wrapping. Outer padding and borders remain supported; their box minimum persists during closing. Put decoration on a child when the closing endpoint must reach zero.

<ComponentExample name="changing-content" />

```tsx
"use client";

import { useState } from "react";
import { Button } from "@/components/cadence/button";
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/cadence/collapsible";

export function ChangingContentExample() {
  const [details, setDetails] = useState(false);
  return (
    <Collapsible defaultOpen>
      <CollapsibleTrigger>Project information</CollapsibleTrigger>
      <CollapsibleContent className="mt-4 rounded-lg border p-4 text-sm">
        <p className="mb-4">Components are copied into your project so you can make them your own.</p>
        <Button variant="outline" size="sm" aria-expanded={details} onClick={() => setDetails(!details)}>
          Toggle extra detail
        </Button>
        {details && (
          <p className="mt-4">
            The disclosure follows content changes and responsive wrapping. Reduced and none modes update its height
            instantly.
          </p>
        )}
      </CollapsibleContent>
    </Collapsible>
  );
}
```

## Custom render

Render Root and Content as sections while preserving the supplied props and measurement children. Content has default div semantics; this example explicitly opts into a named region. Caller classes and styles remain applied to the outer panel.

<ComponentExample name="custom-render" />

```tsx
"use client";

import { useId } from "react";
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/cadence/collapsible";

export function CustomRenderExample() {
  const id = useId();
  return (
    <Collapsible defaultOpen render={<section />}>
      <CollapsibleTrigger id={id}>Support resources</CollapsibleTrigger>
      <CollapsibleContent
        render={<section />}
        role="region"
        aria-labelledby={id}
        className="text-muted-foreground"
        style={{ scrollMarginTop: "6rem" }}
      >
        <a href="/docs/installation">Read the installation guide</a> before adding your first component.
      </CollapsibleContent>
    </Collapsible>
  );
}
```

## Without motion

This named example explicitly sets `none` for the first disclosure. The nested `full` provider restores its recipe, while the system reduced-motion preference still wins. Other examples inherit the site header mode and speed.

<ComponentExample name="without-motion" />

```tsx
"use client";

import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/cadence/collapsible";
import { CadenceProvider } from "@/components/cadence/lib/provider";

export function WithoutMotionExample() {
  return (
    <CadenceProvider mode="none">
      <div className="grid gap-4">
        <Collapsible defaultOpen>
          <CollapsibleTrigger>Instant disclosure</CollapsibleTrigger>
          <CollapsibleContent>No height transition runs here.</CollapsibleContent>
        </Collapsible>
        <CadenceProvider mode="full">
          <Collapsible defaultOpen>
            <CollapsibleTrigger>Nested full disclosure</CollapsibleTrigger>
            <CollapsibleContent>The operating system can still reduce this transition.</CollapsibleContent>
          </Collapsible>
        </CadenceProvider>
      </div>
    </CadenceProvider>
  );
}
```

## When to use

- Optional details for one independent section.
- Advanced settings beside a visible summary.
- Supporting reference notes that users may reveal on demand.

## When not to use

- Use Accordion for a group of labelled sections.
- Use Tabs for peer views sharing one panel.
- Keep essential instructions visible.

## API

### `Collapsible`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` / `defaultOpen` | `boolean` | uncontrolled / `false` | Controlled or initial expanded state. |
| `onOpenChange` | `(open, details) => void` | — | State change request; details support cancellation. |
| `disabled` | `boolean` | `false` | Ignore trigger interaction. |
| `className`, `style`, `render`, `ref` | Base UI Root props | — | Forwarded unchanged, including state callbacks. |

### `CollapsibleTrigger`

All Base UI Trigger props pass through, including `disabled`, `nativeButton`, `render`, `ref`, and
state-based classes/styles. Use `render`, not `asChild`, for a custom element. Supply an accessible name.

### `CollapsibleContent`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `keepMounted` | `boolean` | `false` | Keep closed content in the DOM. |
| `hiddenUntilFound` | `boolean` | `false` | Reveal via browser find-in-page; overrides keepMounted. |
| `className`, `style`, `render`, `ref` | Base UI Panel props | — | Applied to the outer panel; classes merge last. |

All primitive props remain available. A custom render must preserve supplied children and props,
including the natural measurement wrapper. The added `collapsible-content-inner` slot is structural.
Outer padding and borders are supported in both `border-box` and `content-box`; expanded content
retains its natural height. During closing, CSS keeps the outer padding/border minimum until Base UI
hides or unmounts the panel. To reach a visually zero-height endpoint before hiding, put that decoration
on a content child. Caller styles are preserved; padding and borders are never animated.

## Motion contract

| Phase | Properties | Token | Interruptible |
| --- | --- | --- | --- |
| Open / close / content resize | Measured height clamped at zero | `geometry.resize/css-transition` CSS form: `duration.slow` / `ease.out` | Yes, native reversal from current position |
| Initially open | Natural height without entrance | — | — |
| Reduced | Instant height, no transform | Zero duration | Yes |
| None | Instant height, no transform or transition | Zero duration | Yes |

An inner ResizeObserver watches natural content, never the animated panel. Measurements happen after
commit, on resize and when outer classes/styles change. Border-box targets include outer vertical
padding and borders; content-box targets use the natural inner height. Native CSS reversal preserves
position rather than spring velocity. Base UI owns mounting, hidden state and transition completion. No icon animation or extra recipe is added.

## Accessibility

The trigger exposes `aria-expanded` and `aria-controls`. Content retains Base UI's default div semantics;
add a named region only when the content warrants one. Focus stays on the trigger when toggled.
Disabled controls are skipped in normal tab navigation. Keep interactive content outside the trigger.

## Keyboard interactions

| Keys | Action |
| --- | --- |
| Enter / Space | Toggle the focused trigger. |
| Tab / Shift+Tab | Follow normal page order through the trigger and visible content. |

## Responsive behavior

No fixed dimensions or breakpoint-driven state. Natural content is remeasured when wrapping changes.
The root and trigger are unstyled; use caller classes or compose Button for visual feedback.

## Performance

T3 budget: 12 KB gzip. One ResizeObserver per mounted content panel, disconnected on unmount.
Closed content unmounts by default. Initially open server content uses natural height before hydration.
No timers or render-time measurements drive animation.

## Notes for AI

- Use boolean `open`, not Accordion's array value API.
- Keep content lifecycle props on Content and preserve the measurement wrapper.
- Preserve all three exports and the full/reduced/none branch.
- Related: Accordion for grouped sections; Tabs for alternate views.
