## Evidence and limits

`tests/e2e/component-page.spec.ts`: 58 SSR routes / exact source lines / real heading targets / registry-order links; Button three modes × two OS settings, real press scale, URL/history/node/focus retention and clipboard; install denial/retry/preference; four representative pages × two themes × two widths, axe and keyboard table scroll. Existing package-manager and all component suites retained. Final logs and JS measurement are recorded in the handoff.

Source recipes remain CodeBlock feedback.press/state.morph/data.transition/geometry.resize/layout.shared; no new recipe, token, duration or engine. Copy error is static live-region text; success retains the existing morph. The old same-target/live-cancellation audit remains open. No full-library native compatibility claim.
